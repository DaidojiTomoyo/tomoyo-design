# 活字排版采用文档核对

2026-10-27。用户确认「要 活字排版 这个，然后其他的两个我们后续要做到我们的动画库里面去」。本次据此窄更新已批准的首页动效规则；丝网套色仍是既有视觉体系，套色印刷和海岸显影不成为首页默认。

## 实现依据

核对 `content/motion-studies.ts`、`components/home/home-content.tsx`、`motion-study.tsx`、`study-motion-controller.ts`、`localized-text.tsx`，以及 `app/globals.css` 的开场、跳过按钮、滚动和文字过渡规则。采用决定由 `.impeccable/surfaces/app-page-tsx.md` 的末节记录。

- 正式首页默认 `homeMotionDirection = 'type'`，共享活字开场、内容入场、滚动提示和纵向语言交换；没有方案比较栏。原 `HomeMotion` 控制器不再承担首页行为。
- 六个字母各 640ms、间隔 45ms，最后一个在 865ms 形成；完整停留 650ms，后续最长入场 855ms，资源已准备时总编排约 2370ms。180ms 淡入与形成并行，资源准备最多等待 2200ms，不截断形成或停留。
- 正式首页使用 `tomoyo-home-type`，预览使用 `tomoyo-study-type`；只有完整播放才标记已看完。再次访问走内容短入场，语言切换不重新播放开场。首页的资源准备结束文案为「试试效果」或「Explore the effects」。
- 正式首页的可见跳过按钮位于装饰层之外，在形成与停留阶段出现；退场后隐藏。取消同时解除准备等待，版本检查阻止旧异步过程写回。减少动态效果与页面隐藏保留取消路径。
- `sample-arrival` 承担页面入场，`sample-surface` 承担示例材质和演示，外层按钮继续固定命中与焦点。正式首页采用文字纵向交换和阅读细线，海岸视差仅保留在海岸预览。

## 本次记录变化

`DESIGN.md` 仅更新首页动效、相关复制反馈、卡片分层和语言文字过渡，并记录跳过开场控件。原有颜色、字体、圆角、间距及已有组件基础属性保持原值；新增 `button-intro-skip` 只引用现有墨色、纸色和控件圆角。材料与版式规则没有替换。

`.impeccable/design.json` 移除 7 项旧首页纸面揭开、套准旋转与横向步骤编号参数，记录 23 项当前采用的开场、滚动、文字交换和成功反馈参数。已有示例动效参数保持原值，公共缓出曲线仅更新用途描述。组件片段补入实际入场包装层、复制成功反馈与跳过按钮；叙述中的首页特征和 Do 条目与 Markdown 同步。新时长明确属于首页，不作为所有页面的入场模板。

套色印刷和海岸显影的源码与预览保留，后续进入动画库属于后续工作；本次没有把这两种编排写成首页默认或宣称库集成已完成。

## 验证与边界

本次进行源码和文档核对、JSON 解析及文档格式化，没有启动浏览器、修改应用或重跑应用测试。主执行者报告 `pnpm check`、`pnpm build` 通过；浏览器确认首页为活字方向且无比较栏、预览与首页首访记录独立、首页再次访问为 `return`、语言切换保留玻璃效果和中文提示词，以及新跳过按钮立即结束开场。正式静止截图为 `.impeccable/review/desktop.png` 与 `mobile.png`，最终视觉处置由本轮独立审查负责。

减少动态效果、慢资源和失败资源的结论仍限定于源码检查；没有新增真机帧率、跨浏览器或屏幕阅读器结论。

无关漂移未修复：部分已有组件片段仍保留文案改写前的展示文本。当前产品文案以 `content/locales/` 为准；本次未借动效采用更新重写这些例子，也未把缺陷或未采用方案提升为正式规则。
