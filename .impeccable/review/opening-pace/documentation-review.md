# 开场节奏文档核对

2026-10-27。核对范围仅为用户反馈「开场过短」后的候选开场节奏、资源状态和取消行为。本次读取 `content/motion-studies.ts`、`components/home/study-motion-controller.ts`、相关资源状态 CSS，以及 `docs/homepage-motion-studies.md` 和 `docs/homepage-validation.md` 的新增说明；没有启动浏览器、重跑工程测试或重复完整视觉审查。

## 时序与文档一致

开场淡入为 180ms，和字标、套准标记及海岸显影同时开始，不额外累加到总时长。字母动画为 640ms；活字方向的六个字母间隔为 45ms。画面形成时间取套准标记 720ms、最后一个字母结束时间，以及海岸方向的 900ms 显影三者最大值，然后保留完整画面 650ms。

| 方向     | 形成时间计算                     | 完整停留 | 后续最长入场                                   | 资源已准备时总长 |
| -------- | -------------------------------- | -------- | ---------------------------------------------- | ---------------- |
| 套色印刷 | `max(720, 640) = 720ms`          | 650ms    | `200 + 720 = 920ms`，纸面揭开                  | 2290ms           |
| 活字排版 | `max(720, 640 + 5 × 45) = 865ms` | 650ms    | `200 + 3 × 45 + 520 = 855ms`，最后一个预设编号 | 2370ms           |
| 海岸显影 | `max(720, 640, 900) = 900ms`     | 650ms    | `200 + 800 = 1000ms`，示例入场                 | 2550ms           |

控制器等待入场集合中的全部动画结束后才标记 `complete` 并记录方案已播放。这与文档的三个总长一致；总长是当前配置的编排计算，不是采样数据宣称的精确浏览器耗时。再次访问的短入场和语言切换路径没有新增 650ms 停留。

## 资源状态与取消边界一致

字体等待和示例图片解码通过 `Promise.allSettled` 与 2200ms 截止时间竞速；该准备过程和开场形成、停留并行。完整开场只有在准备过程和画面展示都结束后才退场，资源提前准备好不会截断字标。慢资源可以延长等待，2200ms 仍是准备阶段上限，不是完整开场上限。

资源状态从 `pending` 更新为图片可用的 `true` 或降级的 `fallback`；CSS 对后两者均显示「打开预览」，不再把画面停留本身显示为仍在加载。这条中性提示没有承诺图片和字体全部成功加载。

退场动画先接管透明度，再取消具有 `fill: forwards` 的展示动画，避免退场动画释放后旧展示帧重新出现。`skip()` 递增版本、清除计时器、解决仍在等待的准备阶段并取消入场动画；旧异步过程随后因版本不匹配而退出。语言切换和卸载走清理路径，减少动态效果及隐藏标签页也会取消装饰动画。文档对这些职责的描述与源码一致。

本次只分析已保存的 JSON，不新增运行时样本。`press-timing.json`、`type-timing.json`、`coast-timing.json` 分别包含 240、333、224 个样本；从首个形成完成样本到进入退场的观察间隔分别为 647、656、654ms，符合文档中约 650ms 的停留记录。三者停留时资源状态为 `true`、遮片透明度为 1、准备提示隐藏；末样本均为 `complete`、遮片透明度 0，遮罩和变换为 `none`。

`controls.json` 记录三种方向跳过后均为完成状态、遮片透明度 0、横向溢出 0；键盘操作保留玻璃效果与预设焦点，语言切换保留效果并标记为 `language`。六张停留截图的视口与用途采用主执行者的验证记录：1280×720 和 390×844，刻意显示完整开场的停留阶段，不作为首页静止布局或性能结论。
