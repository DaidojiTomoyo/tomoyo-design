# 首页与参数面板参考观察

2026-10-28，通过实际浏览器查看以下公开页面。网页会持续更新，记录仅对应本次浏览。

- [React Bits 首页](https://reactbits.dev/)：首屏展示可操作的背景，带预设与参数；后面继续展示多个真实效果并提供分类入口。演示本身解释了产品用途。
- [Tilted Card](https://reactbits.dev/components/tilted-card)：预览、复制、分享靠近画布；参数包含倾斜、缩放、透视、平滑、光泽、阴影、视差和圆角，并有按行为组织的开关。
- [Blur Text](https://reactbits.dev/text-animations/blur-text)：方向、拆分单位、触发方式、延迟、时长、模糊与距离；参数集合与卡片效果明显不同。
- [21st.dev 首页](https://21st.dev/)：明确的首屏行动和目录演示，后续通过不同作品种类改变版面节奏；复制提示词属于其已有能力。

本项目采用真实演示优先、按效果定义参数、预设起步、可见复制入口，以及有变化的预览尺度。不照搬其深色皮肤或统计数字，不把数量少的现有内容伪装成庞大的目录。

实现约定见 [体验调整简报](../../experience-upgrade-brief.md)。
