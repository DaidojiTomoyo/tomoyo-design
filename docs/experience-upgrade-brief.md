# 首页、目录与详情体验调整

2026-10-28。基于用户对跳转生硬、首页表现不足、目录布局及全站表单控件、详情参数过少的反馈。

这次沿用已确定的纸色、群青、朱红、字体与丝网套色素材。React Bits 和 21st.dev 提供的是展示与交互参考；没有采用它们的品牌、数量、用户评价或商业功能。

## 方向与验收

- 首页（Persuade / Experience）：第一屏直接操作真实效果，快速调整距离、时长或玻璃参数；提示词与详情入口携带当前值。明确进入效果库的按钮，后续用真实预览替换尚未实现的词汇列表。
- 目录（Operate / Experience）：保留用户指定的分类栏；总览用一幅大预览配两幅横向预览，搜索、排序与分类结果保持规则网格。不同效果以照片卡、文字卡、透光材质分别展示。
- 详情（Operate）：大预览和分组参数；宽屏预览与复制工具栏随滚动保持可用，手机为单列和底部复制入口。每种效果拥有不同参数和三个预设，支持滑块、数值编辑、方向及缓动选项。
- 公共控件：一致的输入底色、边界、选中状态与焦点；数字输入 Enter 提交、Escape 取消，超出范围归一化。保留原生输入与单选语义。
- 连续性：路径切换短暂淡入，公共页面祖先不做位移，保持固定工具栏以视口定位；参数查询更新不触发整页过渡，语言切换沿用文字过渡。减少动态效果时不播放页面淡入。不延迟路由来播放装饰，不改变资源加载屏的既有规则。

## 配置边界

| 效果     | 可调项                                                         |
| -------- | -------------------------------------------------------------- |
| 悬停浮起 | 距离、缩放、旋转、阴影、时长、缓动                             |
| 柔和入场 | 方向、距离、模糊、起始缩放、时长、延迟、缓动                   |
| 磨砂玻璃 | 色调、背景模糊、表面不透明度、饱和度、描边不透明度、圆角、阴影 |

效果参数、默认值、校验与序列化由同一规范维护。预览、提示词和分享同步；v1 老链接缺少的新字段补默认值，不接收该效果之外的字段。参数调整后的演示合并短时间内的连续输入，离屏、后台、卸载和减少动态效果时清理。
