# 效果库与效果详情页设计简报

日期：2026 年 10 月 28 日。

状态：用户已批准按 React Bits 分类浏览结构制作的 HTML 草图，并授权实现。效果库、分类页与详情现已接通；本轮沿用「丝网套色」系统，未批准新的全局视觉身份或 token。审查列出的四项修正均已解决，构建、功能验证及未覆盖范围见 [效果库验证记录](effects-library-validation.md)。

## 任务与范围

用户从效果画面出发，找到想要的交互或材质，调整少量参数，再将对应提示词带入自己的项目。目标用户与全球发行、中英文支持等产品事实沿用 `PRODUCT.md`。

本轮实现效果库与详情页的布局、手机重排和关键交互状态。页面属于 Operate 模式：搜索、预览、调参和复制的操作位置清楚、稳定。沿用 `DESIGN.md` 中已确认的纸色、深蓝、群青与朱红，以及中英文字体分工；本简报记录这些页面的结构和局部控件约定。

网站自身的控件保持统一；效果在自己的画布内展示。首页的海岸插画可作为首批卡片效果的共同示例内容，后续效果根据用途选择合适内容。

## 页面职责

| 页面     | 路由                           | 主要任务                           | 完成后的去向                         |
| -------- | ------------------------------ | ---------------------------------- | ------------------------------------ |
| 效果库   | `/[locale]/explore`            | 搜索、筛选、比较画面，选择一个效果 | 对应效果详情                         |
| 分类页   | `/[locale]/explore/[category]` | 查看该类效果的预览网格             | 对应效果详情或其他分类               |
| 效果详情 | `/[locale]/effects/[slug]`     | 操作预览、调参、检查并复制提示词   | 用户自己的 AI 工具，或回到原目录位置 |

三个页面共用顶部导航和左侧分类目录，进入详情后保留目录并标明当前条目。点击分类标题进入分类网格，点击效果名称直接进入详情。详情 URL 不绑定分类，后续重新归类不会更换效果的固定地址。

首页的示例可以连接对应详情。详情支持直接访问；从目录进入再返回时恢复搜索、筛选与滚动位置。切换界面语言保留效果与当前参数，提示词语言独立选择。

## 用户指定的参考与新版结构

用户于 2026-10-28 表示三种草图均不满意，提供 [React Bits 效果目录](https://reactbits.dev/get-started/index)，明确希望按类别分类效果。原来的索引列表、预览优先和顶部分类网格均未获采用；历史草图保留在 `.impeccable/mocks/decision/`，不再作为待选方案或实现依据。

[本次实际浏览记录](research/2026-10-28/reactbits-catalog-review.md)包含目录、分类、详情和手机导航的观察。新版采用以下组织方式：

- **顶部**：紧凑的品牌、效果库入口、使用说明、界面语言。让主要空间留给效果。
- **左侧**：全部效果、分类标题、该类效果名称；分类与当前条目都有明确状态。目录独立滚动，效果数量增加后仍可直接跳转。
- **总览与分类页右侧**：标题、搜索、真实结果数与排序，下方是预览网格。没有营销首屏；卡片主要呈现画面、名称和一句用途。
- **详情右侧**：名称和用途，下方为大预览、重播，以及相邻的参数与提示词区。长提示词放在下方可直接阅读，复制按钮始终容易找到。
- **手机**：左侧目录收进顶部“分类 · 效果目录”入口，展开后保留相同分组和选中项；页面主体为单列。

布局草图继续使用现有纸色、深蓝、群青、朱红与字体分工。本轮没有要求替换网站的视觉语言。

## 分类规则

按词汇手册的主要内容建立分类，使用明确的中文名称和稳定标识：

| 分类       | 标识       | 承载内容                                     | 第一批状态                  |
| ---------- | ---------- | -------------------------------------------- | --------------------------- |
| 动画与交互 | `motion`   | 入场、悬停、点击、滚动、文字及页面开场等行为 | 悬停浮起、柔和入场，共 2 项 |
| 整体风格   | `style`    | 极简、复古、杂志编辑等整体视觉方向           | 有完整示例后开放            |
| 材质与光影 | `material` | 玻璃、纸张、颗粒、光泽等表面与层次           | 磨砂玻璃，共 1 项           |
| 布局与排版 | `layout`   | 网格、叠层、留白、文字编排等                 | 有完整示例后开放            |
| 配色       | `color`    | 冷暖、明暗、饱和度、色彩组合等               | 有完整示例后开放            |

“节奏与手感”先作为标签和参数，例如缓出、弹性、短促、舒缓；不把跨越多类效果的描述与主分类并列。“组合表达”留给后续场景配方。内容增多后，动画类可以按文字、鼠标、滚动、入场等标签细分，避免第一版出现大量空类别。

每个效果只拥有一个主分类，可有多个搜索别名。柔和入场在目录与首页均已归入动画与交互；首页旧版的 Style 分组保留为历史，不再作为内容模型。

## 已实现的页面约定

这些是目录与详情的局部规则，不改写 `DESIGN.md` 的全局身份，也不把首页构图固定为其他页面模板。

| 范围           | 当前约定                                                                                                                                                               |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 目录外壳       | 桌面共用 72px 顶栏、246px 分类栏和右侧内容区；整体最大宽度 1700px。分类栏独立滚动，当前分类用深蓝底与纸色文字，当前效果另有朱红点与 `aria-current`。                   |
| 浏览网格       | 宽屏三列，1150px 以下两列，760px 以下一列。搜索、结果数、排序位于网格前方；卡片的预览按钮与进入详情的名称、说明链接分开。                                              |
| 详情工作区     | 宽屏大画布旁为 300px 参数与提示词区，1150px 以下纵向排列。完整提示词在下方原生 disclosure 中展开；复制和复制链接是两个明确动作。                                       |
| 手机导航与复制 | 760px 以下使用 60px 顶栏和可展开分类目录；选择条目后收起，Escape 收起并返回触发位置。详情底部复制栏预留内容间距及安全区。                                              |
| 字体与控件     | 英文标题继承 Oswald，正文与注释继承 Roboto Mono，中文继承 Noto Sans SC。使用原生搜索、排序、range、select、details 和只读 textarea；输入、正文、可见焦点不随效果运动。 |
| 画布与播放     | 群青纹理画布复用已批准海岸图。固定按钮承接指针或键盘操作，内部表面执行效果；紧凑画布的播放提示是独立真实按钮，至少 44px 高，并为示例文本留出空间。                     |
| 状态与局部样式 | 朱红用于动作和选中标记；纸面与蓝墨承担阅读。页面局部的分隔色、辅助文字色、蓝色焦点环和控件尺寸仅服务此操作界面，未提升为新增全局 token。                               |

效果 slug 固定为 `hover-lift`、`soft-reveal`、`frosted-glass`，不随分类或界面语言变化。详情只显示该效果实际可调的参数：悬停浮起的距离 0–24px、时长 100–800ms；柔和入场的距离 0–40px、时长 100–1500ms；磨砂玻璃的模糊 0–40px、饱和度 1–2。滑块值、提示词和分享参数共同经过 `content/effects/schema.ts` 校验。

版本为 `v=1` 的分享地址保留全部有效参数与 `prompt=en|zh`；界面语言由路由表达。无效值回退并显示说明，不支持的版本使用当前默认配置。直接打开分享链接时，服务端首份 HTML 已包含配置值和对应提示词；首页及动效演示页仍静态生成。

## 效果库的共同交互

- 搜索匹配中英文名称、常见别名和用途，支持混合语言词组。分类由路由表达，搜索词在结果上方可见并可清除。
- 每张卡片或列表行包含名称、一句用途和进入详情的入口。预览播放操作与进入详情分开，避免用户试播时意外跳转。
- 默认显示稳定画布；悬停浮起响应鼠标与可见键盘焦点，所有条目可通过画布或播放按钮主动演示。离开视口或切到后台后停止演示。
- 筛选直接更新结果并保持搜索框和当前焦点；结果卡片没有批量入场动画。
- 无结果时保留输入和筛选，显示清除条件的入口。只有内容加载失败时才显示重试；空结果不表达成故障。
- 排序先支持确定的顺序与名称；有可靠使用数据后再考虑热门排序。

## 效果详情的共同交互

以悬停浮起作为第一张完整详情的检验对象。

1. 名称和一句用途说明当前效果；面包屑明确回到效果库的位置。
2. 预览下方提供重播，参数区提供重置。预览画布保留触发说明，手机上可主动轻点演示。
3. 参数只展示对画面有实际影响的选项。悬停浮起先提供距离与过渡时长，标明 px、ms，保留原默认值。
4. 调参立即更新画面和提示词，取消过期动画并应用当前配置，保留同一示例和命中区域。重置同时恢复画面与提示词的默认参数。
5. 完整提示词可以展开阅读；复制始终使用当前效果、参数和提示词语言。默认要求沿用用户项目的技术栈、内容和设计。
6. 分享链接保留效果与可调整参数；复制提示词与复制链接使用不同的明确标签。

提示词面板使用现有复制反馈规则：操作位置与指针稳定，成功后显示已复制；失败时打开并选中可手动复制的文字。参数变化不自动移动键盘焦点。

效果本身的参数与画布展示工具分开：例如仅用于检查画面的背景切换，不应悄悄进入实现提示词。

## 手机与中英文

新版手机目录、详情和分类展开状态均使用同一响应式样式。详情首屏优先显示效果，参数往下排列；底部保留复制入口，文档流预留其空间。

- 桌面方案先以 1440px 检查；手机以 390px 检查，同时保留 320px 窄屏回退要求。
- 目录在窄屏保留搜索和当前条件，分类收进有明确名称的目录。后续若增加复杂筛选，面板关闭后仍应返回原触发位置。
- 详情顺序为名称、预览、重播、参数、提示词。当前参数直接显示，完整提示词可展开；常用的复制入口保持容易到达。未来长参数组可再按需折叠。
- 页面已为底部复制栏和设备安全区留出空间，不能遮住内容、焦点或最后一项参数。
- 控件使用适合触屏的点击区域；不依赖 hover 才能发现效果名称、说明或主操作。
- 中文使用现有 Noto Sans SC 分工，英文长文按自身语言排版。正式实现新增中文文案时检查本地字体子集覆盖情况。

## 动效与加载

颜色和字体延续首页；目录与详情的运动围绕操作反馈组织。

| 触发               | 设计意图                               | 减少动态效果时           |
| ------------------ | -------------------------------------- | ------------------------ |
| 切换分类、提交搜索 | 更新结果数与当前内容，保留操作上下文   | 直接更新结果与选中态     |
| 进入详情           | 让用户认出刚才选择的效果，尽快操作预览 | 直接显示详情             |
| 修改参数           | 当前画面平滑接续，同时更新对应描述     | 保留可读静态结果和参数值 |
| 切换语言           | 文本变化，保留参数、画布和操作位置     | 直接替换文本             |
| 复制成功           | 沿用已建立的图标与文字反馈             | 保留文字结果，无位移     |

目录和详情先呈现导航与正文，资源等待局限于需要加载的预览区域，并预留尺寸。缓存资源就绪时直接显示；不增加人为等待，也不在路由切换时重复首页开屏。套色印刷和海岸显影进入库后，其编排应在演示画布内运行。

## 实施边界与验收

共用目录框架与三个效果的完整路径均已实现。路由文件仅承担 metadata、参数、查询读取和组合；目录框架与分类浏览放在 `features/catalog/`，详情的调参和提示词操作放在 `features/effect-detail/`，可复用效果定义放在 `content/effects/`。目录与详情共用 `components/effects/` 的预览，搜索、元信息、URL 与复制逻辑分别归入 `lib/`。没有新增依赖、`src/`、独立业务 API 或 iframe 宿主。

预览、参数校验、提示词和分享恢复应读取同一份效果定义。既有首页行为作为迁移时的回归基线；计划目录保持在项目根目录，不引入 `src/`。

本轮按以下项目验证，具体完成情况与证据类型见验证记录：

- 从目录搜索一个效果，进入详情，返回后条件与位置仍在。
- 调参、重播、重置和快速切换保持稳定，双语提示词准确反映当前参数。
- 从分享链接直接恢复有效配置；不合法参数得到清楚的默认值回退。
- 键盘、触屏、减少动态效果、复制失败和无结果状态均有完整路径。
- 将复制出的提示词用于另一个测试项目，检查 AI 生成结果与预览的关键行为是否一致。

本机收藏、场景配方与组合工作台按后续阶段处理。本轮不为尚未可用的功能增加正式导航入口。

目前浏览器验证覆盖目录、分类、详情、语言、复制、分享与返回路径；控制器测试另覆盖减少动态效果、快速重播及取消行为。实际减少动态效果浏览器仿真、复制权限拒绝、网络故障、真机及多浏览器验证尚未完成；将提示词交给外部 AI 测试项目的人工复现评估仍待开展。不得用源码或控制器测试代替这些运行环境的证据。
