# UI 视觉风格与动效词汇手册

本手册整理用于描述 UI 视觉风格、配色、质感、布局和动画效果的常用词汇，适合编写设计需求、搜索效果参考，以及向 AI 描述期望的页面效果。以中文描述词为主，部分附上常见英文。

例如：**现代简约风 + 暖色系 + 纸张质感 + 大留白 + 翻书动画**。

## 1. 动画与交互效果

这一类描述的是：**界面里的元素怎么动。**

| 词汇 | 效果描述 |
|---|---|
| **缩放动画**（Scale） | 元素放大或缩小，例如卡片放大出现、按钮点击后轻微缩小 |
| **淡入淡出**（Fade） | 元素逐渐出现或消失 |
| **滑入滑出**（Slide） | 元素从左、右、上、下移动进入或离开 |
| **弹性动画／回弹动画**（Spring / Bounce） | 元素运动到目标位置后轻微回弹，带有弹簧感 |
| **卡片翻转**（Card Flip） | 卡片绕水平轴或垂直轴翻转，展示正反两面 |
| **翻页／翻书动画**（Page Flip） | 模拟书页翻动，可带纸张弯曲、书脊和阴影变化 |
| **揭幕动画**（Reveal） | 内容像被拉开幕布或揭开遮挡一样逐步显露 |
| **交错入场**（Stagger） | 多个元素按照顺序依次出现 |
| **滚动渐显**（Scroll Reveal） | 页面滚动到某个位置时，内容逐渐进入视野 |
| **视差滚动**（Parallax） | 背景和前景以不同速度移动，形成空间层次 |
| **悬停浮起**（Hover Lift） | 鼠标悬停时，卡片轻微上移并改变阴影 |
| **倾斜跟随**（Tilt） | 卡片根据鼠标位置轻微倾斜，产生立体感 |
| **点击涟漪／水波纹**（Ripple） | 点击位置向外扩散圆形波纹 |
| **呼吸动画**（Breathing / Pulse） | 元素缓慢重复缩放、变亮或变暗 |
| **形变动画**（Morphing） | 一个形状平滑变成另一个形状 |
| **打字机效果**（Typewriter） | 文字逐字出现 |
| **数字递增动画**（Count-up） | 数字从初始值逐步变化到目标值 |
| **流体动画**（Fluid） | 色块或形状像液体一样流动、融合 |
| **粒子动画**（Particles） | 光点、星点、碎片等小元素漂浮或聚散 |
| **共享元素过渡**（Shared Element Transition） | 同一张图片或卡片在页面切换时连续移动、缩放到新位置 |

**有两组特别容易混淆：**

- **卡片翻转**通常是整块平面的正反面旋转；**翻书动画**更强调书页、翻页轴线、纸张弯曲和阴影。
- **滚动渐显**强调“滚动到这里时出现”；**视差滚动**强调“不同层移动速度不同”。

## 2. 动画的节奏与手感

只说“缩放动画”还不够，这些词可以进一步描述它**动起来是什么感觉**。

| 词汇 | 感觉或效果 |
|---|---|
| **平滑过渡** | 变化连续、自然，没有突然跳变 |
| **缓入**（Ease-in） | 开始较慢，随后加快 |
| **缓出**（Ease-out） | 开始较快，接近结束时减慢 |
| **缓入缓出**（Ease-in-out） | 开始和结束较慢，中间较快 |
| **弹簧感** | 带有弹性，可能出现轻微超出和回弹 |
| **阻尼感** | 回弹逐渐减弱，最后稳定下来 |
| **短促利落** | 动画干脆，快速完成 |
| **舒缓轻柔** | 运动较慢，变化柔和 |
| **克制轻量** | 移动距离小、变化幅度小，视觉存在感较弱 |
| **活泼灵动** | 节奏轻快，带有跳动、回弹或错落变化 |

可以这样组合：

> **带轻微回弹的缩放入场动画。**  
> **缓出、短促的卡片上浮效果。**  
> **舒缓、带阻尼感的翻书动画。**

## 3. 整体 UI 风格

这一类描述的是：**整个界面的视觉方向。**

| 词汇 | 常见视觉特征 |
|---|---|
| **现代简约风** | 布局干净、层级清楚、装饰较少、组件样式统一 |
| **极简主义**（Minimalism） | 减少界面元素，突出主要内容，保留较多留白 |
| **扁平化设计**（Flat Design） | 以色块、文字和简单图形为主，减少真实材质和立体装饰 |
| **拟物化设计**（Skeuomorphism） | 模拟现实物品的材质和结构，例如纸张、皮革、机械按钮 |
| **轻拟物风** | 保留适度光影和立体细节，整体仍然简洁 |
| **新拟态**（Neumorphism） | 元素与背景颜色接近，利用明暗阴影形成凸起或凹陷效果 |
| **玻璃拟态**（Glassmorphism） | 半透明面板、背景模糊、边缘高光和叠层效果 |
| **科技未来风** | 常搭配精细线条、几何形状、光效和数据展示 |
| **赛博朋克风** | 暗色背景、霓虹色、高对比、电子或故障元素 |
| **复古风** | 旧式字体、复古配色、颗粒或印刷纹理 |
| **像素风** | 像素图形、块状边缘、复古游戏般的视觉 |
| **杂志编辑风** | 大标题、鲜明的文字层级、讲究图文编排 |
| **新粗野主义**（Neobrutalism） | 粗边框、硬阴影、醒目色块、直接鲜明的布局 |
| **手绘风** | 手绘线条、涂鸦、不规则边缘、插画元素 |
| **可爱卡通风** | 圆润形状、卡通插画、轻松活泼的视觉 |

“现代化 UI”“高级感”“科技感”属于比较宽泛的方向词。补充颜色、形状、光影和排版后，表达会更准确。

例如：

> **现代简约风，大留白，统一圆角，细描边，柔和阴影，清晰的文字层级。**

## 4. 配色与色彩氛围

这一类描述的是：**界面使用什么颜色，以及颜色带来什么感觉。**

| 词汇 | 效果描述 |
|---|---|
| **暖色系** | 以橙、红、黄等偏暖颜色为主 |
| **冷色系** | 以蓝、青等偏冷颜色为主 |
| **中性色系** | 以黑、白、灰，以及米色、灰褐色等为主 |
| **低饱和度** | 颜色较柔和、偏灰，鲜艳程度较低 |
| **高饱和度** | 颜色鲜明、浓烈、醒目 |
| **高明度配色** | 整体颜色较浅、较亮 |
| **低明度配色** | 整体颜色较深、较暗 |
| **粉彩／马卡龙配色** | 浅淡柔和的粉、蓝、绿、黄等色彩组合 |
| **莫兰迪色系** | 常用来描述偏灰、柔和、低饱和的配色 |
| **奶油色系** | 以奶油白、米白、浅杏、浅棕等颜色为主 |
| **同色系配色** | 围绕同一类颜色，利用深浅变化建立层次 |
| **撞色搭配** | 使用差异明显的颜色形成视觉对比 |
| **黑白高对比** | 利用黑白或明显的明暗差突出内容 |
| **渐变配色** | 颜色连续过渡，可做线性渐变、径向渐变或网格渐变 |
| **深色主题** | 以深色背景为基础，搭配较亮的文字和强调色 |

**暖色系和低饱和度是两个不同维度。**

例如：

- **暖色 + 高饱和**：鲜橙、明黄、亮红，容易呈现热烈、活泼的方向。
- **暖色 + 低饱和**：浅杏、灰粉、陶土色，容易呈现柔和、温暖的方向。

## 5. 材质、光影与形状

这一类描述的是：**界面表面有什么质感，细节如何处理。**

| 词汇 | 效果描述 |
|---|---|
| **磨砂玻璃** | 半透明表面，背后的内容呈模糊效果 |
| **半透明叠层** | 多个半透明区域叠加，形成前后关系 |
| **纸张质感** | 模拟纸张的颜色、纹理、边缘或厚度 |
| **颗粒感／噪点纹理** | 添加细小颗粒，让大面积纯色带有纹理 |
| **金属质感** | 利用高光、反射、拉丝纹理等表现材质 |
| **柔和阴影** | 阴影较浅、边缘模糊，形成轻微悬浮感 |
| **硬边阴影** | 阴影边界清楚、偏移明显，视觉更直接 |
| **内凹感** | 元素看起来嵌入背景内部 |
| **浮雕感** | 图形或文字看起来从表面凸起 |
| **霓虹发光** | 元素边缘或周围出现彩色光晕 |
| **弥散光／柔光** | 大面积、边界模糊的光色扩散 |
| **大圆角** | 边角明显圆润，形状更柔和 |
| **胶囊形** | 两端充分圆润，常用于按钮、标签和搜索框 |
| **细描边** | 用较细的线条区分边界和层次 |

可以组合成：

> **纸张质感 + 细颗粒 + 暖白背景。**  
> **磨砂玻璃 + 半透明叠层 + 柔和阴影。**  
> **粗描边 + 硬边阴影 + 高饱和色块。**

## 6. 布局与排版的视觉描述

这些词能帮助说明**页面整体怎么铺开**。

| 词汇 | 效果描述 |
|---|---|
| **大留白** | 内容周围保留较多空白，让视觉更舒展 |
| **紧凑布局** | 元素间距较小，同屏展示较多信息 |
| **卡片式布局** | 将内容拆分为独立卡片，方便分组 |
| **便当盒布局**（Bento Grid） | 不同尺寸的内容块在统一网格中组合排列 |
| **瀑布流布局**（Masonry） | 不同高度的卡片按列紧密排列 |
| **非对称布局** | 左右或上下不完全对称，通过尺寸和位置形成视觉平衡 |
| **大字号排版** | 用醒目的大标题建立视觉重点 |
| **沉浸式布局** | 用大图、视频或大面积内容营造包围感 |
| **层叠式布局** | 卡片、图片或文字部分重叠，形成空间层次 |

## 7. 可以直接套用的组合表达

可以按这个顺序组织需求：

**界面类型 + 整体风格 + 配色 + 质感 + 布局 + 动效 + 动效节奏**

| 想要的方向 | 可以这样描述 |
|---|---|
| **温暖的阅读界面** | 现代简约风，低饱和暖色系，奶油白背景，纸张纹理，大留白，带柔和阴影的翻书动画，节奏舒缓 |
| **科技感数据大屏** | 深色主题，蓝紫渐变，细线描边，局部发光，便当盒布局，数字递增动画，卡片交错入场 |
| **有设计感的作品集** | 杂志编辑风，黑白高对比，大字号标题，非对称布局，滚动渐显，图片轻微视差 |
| **活泼可爱的工具页面** | 马卡龙配色，大圆角，卡通插画，卡片式布局，按钮点击缩放，轻微弹性回弹 |
| **简洁的品牌官网** | 现代简约风，中性色为主，单一强调色，大留白，细描边，悬停轻微上浮，短促平滑的过渡 |

### 把宽泛描述补成可见细节

把比较宽泛的词补成可见细节，会更容易得到期望的效果。例如：

> **“现代化 UI”** → 现代简约、大留白、统一圆角、清晰的文字层级、柔和阴影。  
> **“暖色系”** → 奶油白背景、浅杏色卡片、深棕色文字、陶土橙强调色。  
> **“缩放动画”** → 卡片从 95% 放大到 100%，同时淡入，约 250 毫秒，缓出结束。  
> **“翻书动画”** → 页面以书脊为轴翻动，带轻微纸张弯曲和动态阴影，结束时平稳落下。
