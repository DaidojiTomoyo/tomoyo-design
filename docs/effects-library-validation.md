## 浏览器检查

在 Codex 内置浏览器中检查 1440×900、用户实际视口 1280×720、390×844 和 320×844，覆盖中英文页面。当前证据来自该浏览器环境，未扩展为真机或全部浏览器结论。

| 路径       | 已观察的结果                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------- |
| 目录与分类 | 搜索、分类、排序、空结果和清除可用；目录计数与实际三项内容一致                                                |
| 预览与参数 | 点击或键盘重播、参数调整及重置可用，URL 与提示词反映当前值                                                    |
| 提示词复制 | 已复制文字与当前只读文本域内容相等；手动全选覆盖当时测试提示词的 1461 个字符                                  |
| 分享与语言 | 复制的链接保存当前有效参数和提示词语言；切换界面语言后，两者仍被保留                                          |
| 返回结果   | 搜索条件保留；修正后在生产版 1280×720 视口从目录 190px 进入 Hover lift 详情，点击「返回浏览结果」后仍为 190px |
| 手机导航   | 分类目录能展开；Escape 收起后焦点回到触发位置；选择条目后收起                                                 |
| 手机详情   | 底部复制入口可用，长提示词和参数保持可读，320px 页面无横向溢出                                                |
| 运行日志   | 新标签页的实际检查未观察到浏览器 error 或 warn                                                                |
| 首页回归   | 资源完成后的桌面与手机截图保留原开场和页面构图；导航进入目录，已选示例连接详情，Soft reveal 归入动效          |

收尾审查指出紧凑画布的提示遮挡示例文案，以及播放图标本身不可点击。修正后，在同样的 1440、1280、390、320px 宽度复拍：播放提示为 44px 高的真实按钮，点击和 Enter 都触发同一控制器；测试中观察到上浮 `translateY(-6px)` 及动画中间帧。静置示例与播放提示间距在桌面至少 9.5px、320px 至少 12.75px；柔和入场的间距至少 23.8px，覆盖其 12px 位移。320px 与 1280px 检查无横向溢出。审查者已将这两项和过时文档状态共三项问题评为解决。

后续生产检查曾观察到目录从 190px 返回到 0px；返回链接增加 `scroll={false}` 后，重建并重启生产版本，在相同视口复验得到返回前 190px、返回后 190px。审查者结合源码与主执行者运行证据，将该项评为解决。

## 审查结论

[最终修正评分](../.impeccable/review/effects-library/finish-verdict.md)记录 `disposition: ship`：紧凑画布遮挡、不可点击的播放提示、过时文档状态，以及返回目录滚动位置四项均为 resolved。目录与详情约定写入已批准简报、保留现有 `DESIGN.md` 的做法被接受。该结论覆盖列出的修正项，不代表重新审查整个页面或补足本文列出的未覆盖环境；审查者没有独立运行浏览器。

## 生产页面与元信息

- 直接访问英文界面的玻璃分享地址，可在首屏恢复 `blur=40` 和中文提示词，界面仍为英文。
- 另一份生产 HTML 样本含配置滑块值 `32` 与提示词 `blur(32px)`，说明首份服务端输出已经读取查询参数。
- 不支持的 `v=2` 显示配置回退提示并使用默认值；缺失 slug 显示当前语言的未找到页面。
- 已检查 canonical、语言 alternates 及继承的 Google 验证元标签。现有 Analytics 和 Google 验证接入保持不变。
- 本次缺失路由采用流式响应，实际 HTTP 状态为 `200`，HTML 含 `robots=noindex`。它证明本地化未找到内容和禁止索引标记生效，不代表已验证 HTTP `404`。
