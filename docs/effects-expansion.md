# 效果内容扩充

2026-10-28。用户选择按架构顺序补齐阶段三的「杂志编辑风格」和「便当盒布局」。本轮不加入场景配方、收藏、工作台，也不把套色印刷与海岸显影计作已入库。

## 制作顺序

遵循 [架构方案第 11 节](architecture.md#11-内容生产与项目组织)：定义参数 → 实现预览 → 编写中英文提示词 → 注册目录并生成预览证据 → 验证关键流程。

| 条目         | 分类与地址              | 参数                                                                           | 预设                         |
| ------------ | ----------------------- | ------------------------------------------------------------------------------ | ---------------------------- |
| 杂志编辑风格 | `style` / `editorial`   | 图文位置、标题字形、标题字号、正文字号、正文行高、栏间距、图片占比、分隔线粗细 | 杂志、图像优先、紧凑阅读     |
| 便当盒布局   | `layout` / `bento-grid` | 列数、主块布局、网格间距、圆角、块内留白、行高下限、内容对齐                   | 主次分明、均匀排列、横幅开篇 |

两种样例复用同一组海岸内容与已批准的图像，预览中明确标注示例内容。它们是排版效果：提供普通排列与当前效果的切换，以及窄屏检查，不使用虚假的动画重播。真实响应式布局按预览容器宽度折叠，DOM 阅读顺序保持不变。

详情中的杂志预览在容器不超过 480px 时将图片和正文堆叠；便当盒在不超过 520px 时改为两列、不超过 340px 时改为一列，并取消跨列。目录缩略图保留代表性构图，用更短的示例内容帮助识别；实际断点以详情预览为准。所有参数均进入分享配置和提示词，标题字号是自适应上限，便当盒行高是最小值，不会为了固定高度裁掉正文。

## 实现边界

效果参数与默认值按类别拆分，统一校验、分享和提示词入口不变。已有三种卡片效果沿用原控制器；首页保留其三种示例。新预览及其样式放在 `components/effects/composition/`，不写入路由或全局样式。新分类、搜索、目录数量、元信息和网站地图由注册表生成。中英文界面与提示词语言继续独立。

## 阅读参考后的文案重写

同日，用户要求先上网阅读成熟作者的写作。上一版虽然换了口语词汇，仍在反复劝读者休息、看海和收起手机，段落缺少具体内容。本次阅读了以下选段与访谈；下列观察用于这组海边示例，不概括作者的全部作品。

- [汪曾祺《夏天》选段，人民网](https://culture.people.com.cn/n/2015/0603/c87423-27095649-2.html)：井里冰着的西瓜、切瓜时的声音让读者知道夏天怎样度过。对这组文案的启发是先写动作与眼前的东西，让感受有来处。
- [史铁生《我与地坛》，《上海文学》重刊](https://m.thepaper.cn/baijiahao_5404220)：写园中的常客时，散步路线和脚步声呈现了人与人的差别，日复一日的相遇又带出时间的变化。示例中的叙述者也应有具体观察，不能只对读者发出建议。
- [李娟访谈《我的散文其实就是标准的小说》，南方都市报／中国作家网](https://image.chinawriter.com.cn/n1/2018/0424/c405057-29945286.html)：她谈到反复修订表达、结构与节奏，也谈到故事的发展和个人视角。此次重写检查整段的经过与衔接，避免只替换几个形容词。

两个效果共用的示例改为原创虚构短记《海边的一下午》，保留现有“示例内容”标识。杂志正文写走到礁石边、倒鞋里的沙、看人钓鱼和回程；便当盒各块分别写随身带的水、小路尽头、返程和鞋里的沙。缩略图摘录对应完整正文，英文沿用同一组事情。网页中未引用作者原文。

后续写这类示例时，标题应让人知道段落写什么，正文需要增加具体内容，结尾不必替读者总结人生道理。必要的操作说明仍直接写动作，例如复制提示词和调整参数。以上是此次改写的编辑判断，不作为禁止抒情或口语的机械规则。

中文字体另补 24 个字形，共 614 个请求字符、179004 字节；旧字形全部保留，新旧字符均通过 fontkit 覆盖检查。

`pnpm check` 通过。沙箱内的 `pnpm build` 在编译阶段超过九分钟未完成，停止该进程后在沙箱外重跑通过。浏览器核对中文杂志 1440px、中文便当盒 390px、英文杂志 390px 和英文总览 1280px，默认参数下的新标题、正文及缩略图均未出现文字溢出或裁切。详见[本次检查数据](../.impeccable/review/effects-expansion/copy-research-verification.json)和[杂志文案预览](../.impeccable/review/effects-expansion/copy-research-editorial-preview.png)。
