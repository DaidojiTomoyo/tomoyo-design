# 首页动效方案与动画库预留

2026-10-27。用户先比较三个可操作的整页动效预览，调整开场节奏后确认：“要 活字排版 这个，然后其他的两个我们后续要做到我们的动画库里面去”。

## 已确认的采用决定

- `/en` 与 `/zh` 正式首页采用活字排版，包含资源加载、内容入场、滚动和语言切换。用户最新确认加载层只在资源需要等待时出现，普通首页取消固定展示停留；预览页保留完整编排。
- 正式首页不显示方案比较栏。开屏兼作加载动画，由资源准备和排字编排自动结束，不提供“跳过开场”；原来的预览路由继续提供方案切换与重播。
- 不再记录“是否看过开场”。每次文档加载都检查实际资源；语言切换只传递当前页面内的导航意图，刷新后重新检查资源。
- 套色印刷和海岸显影保留源码、参数和预览，后续作为动画库内容开发，具体待办见文末。

## 预览入口

| 方向     | 中文路由                   | 主要表现                                                               |
| -------- | -------------------------- | ---------------------------------------------------------------------- |
| 套色印刷 | `/zh/motion-preview/press` | 字标错位套准，纸面向右揭开，卡片落版，文字以换版方式切换               |
| 活字排版 | `/zh/motion-preview/type`  | 字母上下排入，开场向上退场，标题归位，中英文文字沿纵向交换             |
| 海岸显影 | `/zh/motion-preview/coast` | 海岸图像显现，画面收拢后露出首页，滚动时图像产生小幅视差，文字由虚到实 |

把路由中的 `zh` 换成 `en` 可查看英文版。顶部可切换方案、重播，也能回到正式首页。预览路由标记为 `noindex, nofollow`，没有加入正式导航。

三种方案共用首页内容与效果配置。正式首页由 `homeMotionDirection = 'type'` 选择活字编排，不再运行旧的轻量印刷控制器。预览页保留独立的工具栏与重播入口。

## 与现有设计体系的关系

本轮延续 `DESIGN.md` 中已确认的「丝网套色」：奶油纸、深蓝与群青、朱红动作，Anton / Oswald / Roboto Mono 的英文字体分工，以及中文 Noto Sans SC 字阶。纸纹、蓝色油墨与海岸仍使用原来的三张栅格素材；没有新增字体家族或依赖。

活字排版的大字开场、滚动标题、阅读细线和纵向文字切换已经用于首页。它们是首页的表达，不构成其他路由必须播放的入场模板。套色印刷和海岸显影的专属编排仍是动画库预留内容。

`DESIGN.md` 与 `.impeccable/design.json` 同步首页已采用的动效规则。两者的部分组件示例仍显示改写前的文案，当前文案以 `content/locales/` 为准；本次只同步采用决定涉及的规则，不扩展修改其他既有设计。

## 文案

标题改为“试试效果，再复制提示词。”和“Try an effect. Get the prompt.”。分类说明写清具体变化，使用说明围绕选择、复制和提交现有组件展开。示例卡片使用简短的海边场景文字；没有增加用户数、评价、性能承诺或未实现的功能。技术提示词中的参数和行为要求保持不变。

## 动效行为

- 服务端 HTML 默认处于 `checking`，CSS 从首帧隐藏正文，先保留纸面背景；只有等待超过 250ms 才显示活字加载。资源快速就绪时直接释放正文，不播放遮片或透明度入场。字体、首屏海岸图、纸纹和蓝色纹理均纳入等待，纹理从 HTML 预加载，图片等待解码。
- 控制器接管后进入 `loading`。资源就绪后，如果加载层还未出现便直接完成；已经出现则接续剩余的字标形成，再平滑退场。普通首页不额外停留 650ms。预览页和主动重播从首帧呈现，保留形成后 650ms 停留，供完整观看。
- 不展示虚构百分比。准备阶段结束后，正式首页显示“试试效果”，演示页显示“打开预览”，不会在图片失败时声称全部加载成功。
- 每次刷新走同一资源检查，不读取播放记录；缓存命中和慢网络自然产生不同等待结果。点击预览页“重播开场”可重新观看完整过程。
- 加载期间开屏承接点击、正文不进入 Tab 顺序，页面暂时锁定滚动；点击、键盘、触屏和滚动不会提前结束开屏。进入内容入场时恢复交互。
- 分类标题和使用说明随首次进入视口播放；使用说明的细线反映阅读位置。海岸方案的图像视差只在可见时更新。
- 语言切换使用 React ViewTransition，仅为文字建立过渡，不重新播放开场；保留所选效果、提示词语言和锚点。不支持原生过渡时，首页与预览页均提供短文字入场。
- 页面入场操作 `.sample-arrival`，示例自身的效果操作 `.sample-surface`，避免两个动画控制器同时写入同一元素的变换。
- 减少动态效果时关闭开场、滚动位移和语言过渡；正文默认可见。隐藏标签页取消运行中的装饰动画，组件卸载时释放观察器、帧请求与监听。
- 禁用 JavaScript 时由 `noscript` 直接显示静态内容；脚本一直未接管的 `checking` 阶段，CSS 在 6 秒后移除遮片并恢复正文、滚动。迟到的接管不会盖回正文；已进入 `loading` 的真实资源等待不受这条脚本恢复规则干扰。

资源全部成功为 `ready`，有资源失败为 `degraded`，仍有请求挂起超过 10 秒为 `timeout`，卸载中断为 `aborted`。失败和超时允许进入可用页面，状态不冒充加载成功。10 秒是故障退出上限，不是正常开场时长。资源状态判断独立于视觉编排，可用 `pnpm test` 验证。

### 预览页的完整开场节奏

| 方案     | 字标与画面形成    | 完整停留 | 页面展开与入场 | 资源已就绪时的编排总长 |
| -------- | ----------------- | -------- | -------------- | ---------------------- |
| 套色印刷 | 720ms             | 650ms    | 920ms          | 2290ms                 |
| 活字排版 | 865ms，含逐字间隔 | 650ms    | 855ms          | 2370ms                 |
| 海岸显影 | 900ms             | 650ms    | 1000ms         | 2550ms                 |

时长以 `content/motion-studies.ts` 和编排为准；表格仅适用于预览或主动重播，按及时接管、资源就绪计算，不能作为首页加载时间。预览的开屏背景从首帧不透明，字标用 CSS 形成，退场由 Web Animations API 接管。资源提示独立更新；切换语言、卸载或减少动态效果时，取消动画并释放等待中的准备阶段。

## 实现位置

- `content/motion-studies.ts`：方案名称、双语说明和动效参数。
- `features/home/home-page.tsx`：正式首页与预览共用的内容。
- `features/home/motion/`：`motion-shell`、`opening-screen`、`opening.css` 负责首帧；`controller` 连接资源、字标、内容入场与滚动；`resource-readiness` 收集实际资源，`resource-barrier` 处理成功、失败、超时与取消。
- `features/home/effects/`：效果预览、分类、提示词控件和交互 hooks；与整页加载分开。
- `components/motion/localized-text.tsx`、`components/navigation/language-switch.tsx`：跨页面文字过渡与语言路由，共享导航逻辑放在 `lib/navigation/`。
- `features/home/styles/`：各区域样式及响应式规则；全局文件只保留设计变量和基础样式入口。
- `app/[locale]/motion-preview/[direction]/page.tsx`：六个静态预览页面。

## 动画库后续工作

套色印刷与海岸显影已确认收入后续动画库，本次保留实现，不提前开发库页面。接入时需完成以下内容：

- 将现有整页编排整理为可独立播放的演示，区分开场、内容入场、滚动与文字切换，保留当前节奏供对照。
- 编写中英文名称、效果说明和 AI 提示词，提示词明确时长、触发条件、中断与减少动态效果行为。
- 把动画参数和提示词连接到同一份配置，供重播与后续调参使用，避免演示和描述分离。
- 接入效果目录和详情页，并验证键盘、触屏、重复播放、慢资源及减少动态效果路径。

完成这些步骤前，`motion-preview` 仍是内部演示入口，不在正式导航中冒充已经上线的动画库条目。
