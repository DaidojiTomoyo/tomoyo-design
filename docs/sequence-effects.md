# 套色印刷与海岸显影入库

2026-10-28。按此前确认的动画库计划，将套色印刷与海岸显影接到现有目录和详情页。当前共有七个效果，其中动画与交互分类有四个。首页继续使用活字排版加载逻辑及原有三项效果展示。

## 入口与场景

- 套色印刷：`/zh/effects/overprint`、`/en/effects/overprint`。
- 海岸显影：`/zh/effects/coastal-reveal`、`/en/effects/coastal-reveal`。
- 两项均支持名称、别名搜索，沿用分类、排序、返回位置及分享功能。

| 场景     | 套色印刷                                   | 海岸显影                                 |
| -------- | ------------------------------------------ | ---------------------------------------- |
| 开场     | 字标双层错位套准，纸面向右揭开             | 图像由虚到实，遮片从上下向中间收拢并淡出 |
| 内容入场 | 图文带少量旋转归位，标题与正文错开裁切显现 | 图文从模糊、轻微缩放和位移中显现         |
| 滚动     | 预览内各段进入时播放一次                   | 同样按段入场，图像另有滚动视差           |
| 文字切换 | 旧文向左裁去，新文从右侧显现               | 旧文模糊淡出，新文由模糊淡入             |

每个详情只在预览区域内播放。目录默认静止；开场与入场主动播放，滚动场景使用真实滚动区域，也支持键盘。文字切换演示只改变示例语言，界面语言和提示词语言仍各自独立。示例复用 Composition 中已调整的海边散步内容与现有海岸图片，没有另写抽象口号。

## 参数与预设

每项共有八个配置字段，包含场景选择。面板依据 `scenes` 显示当前实际生效的参数，提示词也按场景生成。分享链接保存完整配置，切换场景后可以找回之前设置的值；选择预设保留当前场景，重置恢复完整默认配置。

| 参数     | 范围                  | 适用场景                 |
| -------- | --------------------- | ------------------------ |
| 成形时间 | 300–1600ms，步长 20ms | 开场                     |
| 停留时间 | 0–1800ms，步长 50ms   | 开场演示                 |
| 过渡时长 | 300–1600ms，步长 20ms | 全部                     |
| 错开时间 | 0–120ms，步长 5ms     | 开场、入场、滚动         |
| 移动距离 | 0–60px                | 开场、入场、滚动         |
| 套色偏移 | 0–24px                | 仅套色：开场、文字       |
| 旋转角度 | −6–6°，步长 0.5°      | 仅套色：开场、入场、滚动 |
| 模糊程度 | 0–12px                | 仅显影：全部             |
| 起始缩放 | 1–1.16，步长 0.01     | 仅显影：开场、入场、滚动 |

套色预设为原版套色、快速套准、大幅错位；显影预设为原版显影、快速显影、缓慢显影。默认开场总长分别为 2290ms、2550ms，与原演示节奏一致。总长计入成形、停留、遮片退场后 200ms 开始的内容入场，并由同一时序函数计算目录说明和提示词。

## 播放与资源边界

播放前等待当前预览字体和图片解码，成功后才开始，失败或 10 秒超时保留静态内容并允许重试。此等待不计入演示时长。开场中的停留用于让用户观察效果；提示词明确要求真实加载屏按资源状态结束，不能把停留当网络进度。本轮没有更改首页资源屏障，也没有新增跳过开场。

播放时重复点击不会从头开始。暂停保存当前帧，继续恢复播放；快速修改参数先从当前帧平滑归稳，再合并为一次重播。切场景、离屏、后台和卸载会取消动画或准备任务。减少动态效果时显示可读的静态结果，换字直接完成。滚动监听为 passive，视差更新合并到一帧一次；暂停后继续会重新检查尚未显现的段落。

两个文本版本共用预留高度，只有当前文本进入辅助技术的阅读内容。播放和暂停控件位于动画层之外。英文场景选项采用两列，320px 下仍可完整阅读；较矮的桌面视口会收紧预览高度，便于同时操作参数和播放。
